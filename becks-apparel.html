Tampilan & Fitur Unggulan

Showcase Visual

1. Canvas Kustomisasi 2D Interaktif

Pelanggan dapat merancang jersey secara mandiri: memilih warna, pola, tipografi nama/nomor, dan mengunggah logo. Hasil kustomisasi diekstrak menjadi metadata JSON (Fabric.js `canvas.toJSON()`) untuk presisi cetak 100% pada tim produksi.

2. Pembayaran Midtrans QRIS & RajaOngkir

Integrasi otomatis Webhook Midtrans untuk verifikasi transaksi instan. Dilengkapi kalkulasi ongkos kirim real-time berbasis provinsi & kota tujuan menggunakan RajaOngkir API serta transfer Bank Mandiri.

3. Panel Admin Filament PHP 3

Dashboard manajemen lengkap untuk pengelola toko. Mengontrol stok bahan baku (kain/tinta), katalog paket jersey, verifikasi pembayaran manual/otomatis, penanganan klaim retur, serta laporan penjualan PDF/Excel.

4. Real-time Tracking & Invoice WhatsApp

Notifikasi status produksi real-time via WebSocket PrivateChannel (Laravel Reverb & Echo). Saat status berubah menjadi "Paid", Laravel Horizon secara asinkron men-generate Invoice PDF dan mengirim pesan WhatsApp via Fonnte API.

Arsitektur 4 Pilar Aktor

Multi-Role Authorization

Sistem didesain menggunakan **Spatie Laravel-Permission** untuk memisahkan hak akses dan alur kerja menjadi 4 peran utama secara transparan:

1. Pelanggan (Customer)

Akses penuh ke antarmuka toko dan kustomisasi desain.

  • Desain jersey mandiri via Fabric.js Canvas
  • Checkout QRIS / Mandiri & Kalkulasi Ongkir
  • Tracking tahapan produksi real-time
  • Unduh Invoice PDF & Pengajuan Retur

2. Administrator (Admin Toko)

Mengelola operasional toko dan verifikasi pesanan.

  • Dashboard Filament PHP 3
  • Manajemen Produk & Stok Bahan Baku
  • Verifikasi Pembayaran & Approval Retur
  • Input Nomor Resi Kurir & Ekspor Laporan

3. Tim Produksi (Factory Floor)

Portal khusus eksekusi dan manufaktur jersey.

  • Dashboard Antrean Pesanan "Paid"
  • Buka File Desain JSON untuk Mesin Printing
  • Update Tahapan: Antrean → Jahit → QC → Siap Kirim
  • Pencatatan konsumsi kain & tinta otomatis

4. Manajemen / Owner

Analitik bisnis tingkat eksekutif.

  • Executive Dashboard Analitik Penjualan
  • Monitoring Laba / Rugi & Tren Produk
  • Evaluasi kecepatan siklus produksi
  • Laporan akumulasi transaksi bulanan
